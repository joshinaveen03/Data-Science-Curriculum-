# Data Science Curriculum – NumPy & Pandas

## Overview

This repository contains instructional content developed for Grade 11 students to learn Python-based data analysis using NumPy and Pandas libraries.

The curriculum is designed to introduce learners to fundamental concepts of data manipulation, analysis, and visualization through practical examples and hands-on activities.

## Learning Objectives

By completing this module, students will be able to:

* Understand the role of NumPy and Pandas in data science.
* Create and manipulate NumPy arrays.
* Perform mathematical operations using NumPy.
* Work with Pandas Series and DataFrames.
* Import, clean, and analyze datasets.
* Generate basic insights from data.
